# GitHub公開前チェックリスト

- [ ] GAS・PythonのコードにAPIキー、Botトークン、Webhook URL、サービスアカウント鍵がないことを再確認
- [ ] `.env`、サービスアカウントJSON、`.clasp.json` がGit管理対象外であることを確認
- [ ] `appsscript.json` 内の匿名アクセス設定を理解し、READMEに本番環境のデプロイURLを掲載しない
- [ ] 参加者ID、DiscordチャンネルID、スプレッドシートID、実際の購入履歴・表示名が含まれないことを確認
- [ ] ブラウザ画面やDiscord通知の画像は参加者情報・サーバー情報を隠してから追加
- [ ] `git status` / `git diff --cached` で公開する全ファイルを目視確認
- [ ] GitHubにpushする前に秘密情報の検出ツールを用いて検査（例：gitleaks）
- [ ] クローンだけで動作しないこと、本人認証がないことをREADMEで明記
- [ ] 公開版でのコード変更を本番GASへ `clasp push` しない

**注意**：`.gitignore` は未追跡ファイルの除外ルールであり、すでにGit履歴にコミットした秘密情報を消す機能ではありません。秘密情報をpushしてしまった場合は失効・再発行と履歴からの除去が必要です。
