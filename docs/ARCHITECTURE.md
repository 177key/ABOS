# システム構成メモ

## コンポーネント

1. **GAS Webアプリ**：`gas/BetPage.html`、`gas/馬券Webアプリ.js` がUIとサーバーAPIを提供。
2. **馬券購入・精算ロジック**：`gas/馬券購入.js`、`gas/レース精算.js`、レース情報取得・大会切り替えの各ソースが処理。
3. **Google Sheets**：レース、参加者、購入履歴、ポイント、通知キューなどの保存先。
4. **Python Bot**：`discord-bot/main.py` が「通知キュー」を15秒間隔で監視し、Discordへ送信。

## 通知キューの設計

通知キュー：A列=通知ID、B列=通知先、C列=JSON、D列=状態、E列=作成日時、F列=送信日時、G列=DiscordメッセージID、H列=エラー。

未送信を取り出し「送信中」に更新してからDiscordへ投稿し、成功なら「送信済」、例外時には「要確認」に更新する。送信成功後の状態更新が失敗するケースもありうるため、厳密な exactly-once 配信ではない。要確認・送信中が残った場合のオペレーションは運用上の課題。

## 公開版の注意

- 本番のGASプロジェクトへの紐づけ情報 `.clasp.json` は同梱しない。
- 外部の実データや本番URLは含めない。
- `appsscript.json` は取得時のマニフェストを含むため、Webアプリのアクセス権限設定を本番推奨とみなさないこと。
- リポジトリの内容は静的なコード紹介であり、稼働デモを公開するものではない。
